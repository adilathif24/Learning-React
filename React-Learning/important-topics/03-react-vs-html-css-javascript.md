# React vs HTML / CSS / JavaScript

| Technology | Purpose | Example |
|---|---|---|
| HTML | Structure | `<h1>Hello</h1>` |
| CSS | Style | `.box { padding: 10px; }` |
| JavaScript | Logic / behaviour | `button.addEventListener(...)` |
| React | Component-based UI | `<Button />` |

## Explanation
HTML structures the page, CSS styles it, JavaScript handles behaviour, and React helps organize UI as reusable components.

## Interview Question
**Q: How is React different from HTML, CSS and JavaScript?**

**Answer:** HTML provides structure, CSS styling, JavaScript logic and behaviour, while React is a JavaScript library focused on building component-based user interfaces.
