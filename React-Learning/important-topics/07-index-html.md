# index.html

## Purpose
`index.html` is the main HTML file where the React application is mounted.

## Example
```html
<body>
  <div id="root"></div>
  <script type="module" src="/src/main.jsx"></script>
</body>
```

## Explanation
The `root` div is the DOM element used by React as the mounting point.

## Interview Question
**Q: Where is a React application mounted in a Vite project?**

**Answer:** The React application is mounted into the DOM element with the `id="root"` in `index.html`.
